# SCAT自動追尾システムの仕様書
スリットガイドカメラを用いて赤道儀による自動追尾を実施するプログラムの仕様書

## 追観測ロジック
### 概要
 - 1.カメラ撮像準備
 - 2.事前にslit中心の位置を検出
 - 3.追尾モードオンを検知
 - 4.slit guideカメラで天体をループ撮像
 - 5.撮像写真から点源の重心とslitの中心を検出し、ズレpixel数を算出
 - 6.ズレpixel数に補正係数を掛け、RaDec補正値を補正
 - 7.RaDec補正値を赤道儀に発信
 - 8.5から繰り返し実行
    - この際、補正係数の更新を実施する
 - 9.追尾モードオフを検知で最後の8実行を基準としてプログラム終了

### 詳細
1. カメラ撮像準備
    <<方法1>> SCAT自動観測プログラム仕様（本来の仕様だが、現段階では実装しない）
    - SCAT自動観測プログラムにて観測準備プロセスにて準備開始の命令を発信
    <<方法2>> 自動追尾機能用のプログラム仕様（今回実装）
    - 自動追尾プログラム用のstreamlitアプリを起動し、準備開始ボタンを押下したら開始
    <<共通>>
    - slit guideカメラ(Atik314L+)接続
    - 冷却開始(温度は.config参照)
    - 冷却完了をもって終了と判断し、2に移動
2. 事前にslit中心の位置を検出
    - slit判定用写真(flat_for_guide_detector.fit)を読み込み
    - slit中心位置を計測
    - 中心位置を変数として保持して終了と判断
    - 3の開始が入力されるまで待機
3. 追尾モードオンを検知
    <<方法1>> SCAT自動観測プログラム仕様（本来の仕様だが、現段階では実装しない）
    - 広視野カメラでの導入が完了したと判断した後に追尾モードオンの命令を発信
    <<方法2>> 自動追尾機能用のプログラム仕様（今回実装）
    - 自動追尾プログラム用のstreamlitアプリにて、追尾開始ボタンを押下したら開始
4. slit guideカメラで天体をループ撮像
    - atik314L+で撮像
    - 露光時間は.config参照
    - 撮像は繰り返し実施し、file名[slit_guide_image_loop.fit]として保存し続ける
    <<方法2>> 自動追尾機能用のプログラム仕様（今回実装）
    - 自動追尾プログラム用のstreamlitアプリ起動時は、撮像画像をアプリUIの画像表示画面にて表示し続ける
    <<共通>>
    - 終了の判断はない、4を開始した直後に5も開始
5. 撮像写真から点源の重心とslitの中心を検出し、ズレpixel数を算出
    - 複数(5個以下)の点源の重心を算出し、.config記載の明るさの点源を対象と判断（基本は最も明るい天体）
    - slit重心から点源重心までのズレpixel数をx,y方向で記載
    - ズレpixel数が計算し終わったら終了して6に移動
6. ズレpixel数に補正係数を掛け、RaDec補正値を補正
    - .configの初期RaDec補正値を参考にし、ズレpixel数をズレRaDecに変換
    - 変換が終了すると7に移動
7. RaDec補正値を赤道儀に発信
    - MoTのコントローラーにRaDec情報を発信(client_sender_v2.py参照)
    - 発信をもって7終了し、5を再開
8. 4から繰り返し実行
    <<方法1>> SCAT自動観測プログラム仕様（本来の仕様だが、現段階では実装しない）
    - 観測リストの情報に沿って対象天体の観測終了. カメラの終了処理は別プログラムで実施
    <<方法2>> 自動追尾機能用のプログラム仕様（今回実装）
    - 自動追尾プログラム用のstreamlitアプリにて、追尾終了ボタンを押下したら終了開始
    - 4のループ撮像を停止し、5~7のループの現在実行が終わり次第終了し、9に移動
9. 
    <<方法2>> 自動追尾機能用のプログラム仕様（今回実装）
    - 自動追尾プログラム用のstreamlitアプリにて、追尾終了を表示
    - 自動追尾プログラム用のstreamlitアプリにて、カメラ接続オフ押下でatik314L+カメラ接続切断

## 構成

```text
scat_guide_tracking_system/
├─ auto_guide.ipynb          # FITS画像を用いたスリット位置検出の試作
├─ src/
│  ├─ base__atik_camera_contloer.py         # Atikカメラ(314L+, 460EX)の ASCOM 制御と FITS 保存
│  ├─ base__point_detector.py         # 画像から点源やslitの重心を検出
│  ├─ base__fits_utils.py          # FITS ユーティリティ用の予約ファイル
│  ├─ base__client_sender.py          # 赤道儀(MoT)へのRaDec送信手段
│  └─ auto_guide.py         # Atik 314L+ の ASCOM 制御と FITS 保存
├─ pictures/                 # 画像・FITS の保存場所
│  ├─ 01_spectroscopic_images/
│  ├─ 02_slit_guide_images/
│  ├─ 03_wide_range_images/
│  └─ 99_temporal_images/
├─ test_notebook/            # Atik カメラ撮像の検証用ノートブック・依存関係
└─ test_all/                 # 追尾処理の初期検証ノートブック
app_auto_guide.py          # 自動追尾をUIで管理するstreamlitのapp
.config               # プログラムで利用する変数の初期値などを記載した設定ファイル
```

## 必要環境

- Windows 10 / 11
- Python 3.11 系（`test_notebook/requirements_atik314.txt` では 3.11.9 を推奨）
- Atik 314L+ のドライバおよび ASCOM Platform
- ASCOM の ProgID `ASCOM.AtikCameras.Camera` が利用可能であること
- uv(observation直下)
- プログラムは全てuv環境下で実行する
