# SCAT 自動追尾アプリ 利用マニュアル

## 概要

ガイドカメラで繰り返し撮像し、スリットと天体の重心から位置のズレを求め、西村MoTへ相対補正を送るアプリです。起動ファイルは `app_auto_guide.py` です。

- 左上：撮像画像。検知したスリット中心を黄色、選択した天体を赤で表示します。
- 左下：画像輝度ヒストグラム、コントラスト設定、RA/Decの補正gain。
- 右側「基本操作」：カメラ接続・冷却・撮像・自動補正の操作と状態表示。
- 右側「開発用オプション」：MoTの電源、恒星追尾、ドームなどの操作。

画面の更新間隔は0.5秒です。画像は露光・読み出し・保存が完了してから更新されるため、必ずしも0.5秒ごとに新しい画像になるわけではありません。

「カメラ電源ON/OFF」はASCOMによる接続／切断です。カメラの物理的な電源スイッチは操作しません。「追尾ON/OFF」は画像解析による自動補正の開始／停止で、MoTの恒星追尾モードとは別の操作です。

## プログラムの使い方

### 利用前の準備

1. ガイドカメラの電源・USB接続を確認します。ASCOMとカメラドライバがインストールされている必要があります。
2. MoTを起動し、MoTの「制御」タブでコントローラ電源をONにします。観測対象を導入し、必要な恒星追尾・ドームの準備を行います。

### 起動方法
**管理者としてPowerShellを起動**し、以下コマンドを実行します。

```powershell
Set-Location 'C:\Users\domepc6-tsuboi\work\observation\scat_observation\scat_guide_tracking_system'
uv run python .\launch_admin.py
```

補足：
   通常のPowerShellから実行すると、管理者権限への昇格確認が表示されます。ただし現在のランチャーは昇格先を非表示で起動するため、元のPowerShellのCtrl+Cでは停止できない場合があります。終了操作を行うためにも、最初から管理者PowerShellを使用してください。

ブラウザが自動で開かない場合は、起動ログのLocal URLを開きます。標準設定は `http://127.0.0.1:8501` です。二重起動は避けてください。

### 追尾開始方法

「基本操作」タブで以下の順に操作します。

1. **カメラ電源ON**：カメラに接続します。コネクト状態がON、操作状態が準備完了になるのを確認します。
2. **目標温度を設定 → 冷却ON**：目標温度は初期値0℃です。準備完了になるまで待ちます。冷却ON表示は冷却スイッチの状態を示し、目標温度への到達とは区別します。
3. **露光時間を設定**：初期値は0.5秒です。入力をEnterなどで確定します。ループ撮像中の変更は次のフレームから適用されるため、要求値と適用値を確認してください。
4. **ループ撮像ON**：画像とFrame番号が更新されることを確認します。この段階では自動補正は行いません。
5. **画像・gainを確認**：必要に応じてコントラスト手動設定をONにし、下限・上限を指定します。手動設定をOFFにするまで指定値を使用します。gainはRA/Dec別に正負の有限値を入力でき、適用ボタンは不要です。現在のUIではgain補正を自動／手動で選択できます。
6. **スリット位置検知**：（直近でスリットガイドカメラの位置変更をしていない場合、後述の*スリット初期値を利用**を利用ください）照明をONにして校正用の画像を撮像し、スリット全体が写っていることを確認して押します。（位置は再検知またはapp終了まで保持します。照明をOFFにして天体を撮像しても、スリット位置は固定です。）

   前回の校正結果を使う場合は **スリット初期値を使用** を押します。画像サイズが違う場合は適用できません。カメラの向き・ROI・ビニング・光学配置を変えた場合も、照明ON画像で再検知してくださいｓ。
7. **天体位置検知**：明るい順に最大5個の光源を一覧表示し、設定順位の光源を赤で表示します。この操作だけでは望遠鏡へ送信しません。
8. **追尾用calibration**：天体が視野内にある状態で押します。ループ撮像を一時中断して基準画像を1枚撮像し、RA +1分角 → RA −2分角 → Dec +1分角 → Dec −2分角を順に相対送信します。各移動後に3秒待ち、新しい画像を1枚ずつ撮像します。負方向の移動は−120秒角として扱い、直前画像との差から2×2の変換行列［度/pix］を推定します。応答が不整合・天体の対応が不明・行列が不安定な場合は校正を採用しません。
   各移動後の天体位置を緑点で順次記録します。校正後はループ撮像を自動再開し、再開後10枚目の撮像完了時に緑点をすべて消します。基準画像と校正用4枚はこの10枚に含めません。終了位置は開始位置からRA −1分角、Dec −1分角です。自動で元の位置には戻しません。最終成功日時はボタンの右列に表示します。
9. **自動追尾ON**：校正成功後に押します。固定した変換行列にpixelずれとgainを適用し、度から秒角へ換算してclient_senderの相対guide命令で補正します。両軸10pixel以内なら送信しません。送信後3秒待ってからの画像で次の補正を判断します。行列は追尾中に学習更新しません。gain初期値は1で、自動モードでは各軸4連続のスリット通過で20%減、4連続の遠ざかりで5%増とします。

補足：
   追尾校正はアプリ稼働中のみ保持します。再起動・画像サイズやカメラ向きの変更後には再校正してください。校正を途中で停止する場合は「ループ撮像OFF」を押します。停止・失敗時にも復帰移動や通信の自動再送はしません。

   スリット位置の再検知は自動追尾を停止してから行います。検出・保存失敗時は前回の保持位置を変更しません。現在座標取得・送信の失敗時は追尾を停止し、自動再送は行いません。照明ONのスリット校正は既定で画像全体を探索し、旧 `slit_center_hint_fraction` は使いません。必要な場合は `.config` に `slit_calibration_roi = [x0, y0, x1, y1]` を追加して探索範囲を絞れます。

   最新画像は `.config` の `output_path` に指定した同名FITファイルへ更新保存されます。標準設定では `pictures/02_slit_guide_images/slit_guide_image_loop.fit` です。全フレームの履歴保存ではありません。

   TCP応答や画面上の補正値だけでは実際の鏡筒移動は確認できません。現在座標や次の撮像結果も確認してください。

### 終了方法

1. **追尾OFF**：自動補正を停止します。ループ撮像は継続します。
2. **ループ撮像電源OFF**：撮像を停止します。このボタンは物理電源を切りません。現在の露光・読み出しが完了するまで待つ場合があります。
3. **冷却OFF**：冷却を停止し、状態表示がOFFになることを確認します。カメラの取り扱い手順に従って温度の復帰を待ちます。
4. **カメラ電源OFF**：カメラ接続を切断し、コネクト状態がOFFになることを確認します。
5. appを実行している管理者PowerShellで **Ctrl+C** を押します。ブラウザを閉じるだけではサーバーは終了しません。

MoTの恒星追尾停止やドームの閉鎖は、この手順では自動実行されません。
MoTから自身で実行してください。
